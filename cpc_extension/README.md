# AI patent CPC/text extension

This project investigates the technology composition behind Qualcomm's 2021–2023
classifier-negative grant expansion and NVIDIA's ML shift between 2014–2016 and
2021–2023. It uses 7,813 specified grants from the original supplied extract, with
official USPTO PatentsView CPC, titles, abstracts and filing dates. The focused
report omits the preceding company/merge-completeness discussion.

Open `outputs/technology_report.md` for the illustrated report.
The primary derived dataset is generated locally as `data/analysis_patent_cohorts.csv.gz`; large/binary data are not committed directly to this repository.

## Reproduce locally, without downloading the bulk corpus

Python 3.12 was used. In a compatible environment:

```bash
python -m pip install -r requirements.txt
python run_pipeline.py
```

The ZIP includes the original comparison frame and all filtered government
metadata used by this extension. The offline runner regenerates feature columns,
all tables, six PNG/SVG figures, reports, research log, verification and archive.
There is no random sampling or fitted predictive model. Results are deterministic.

## Rebuild government subsets from scratch

```bash
python run_pipeline.py --refresh-bulk
```

This downloads about 2.75 GB of compressed, fixed-release metadata to `cache/`,
verifies every published MD5 and byte count, streams the tables and retains only
the comparison IDs. The source is the final PatentsView release, dated
December 31, 2024, deposited by USPTO at https://zenodo.org/records/15783125.
The target one-to-many CPC rows are kept intact; a separate membership layer
deduplicates patent/subclass pairs for counting. Bulk cache files are reproducible
intermediates and are excluded from the deliverable ZIP.

`02_extract_enrichment.py` reuses validated extraction checkpoints. To force a
fresh stream scan, remove `data/g_*_extraction_audit.json` and rerun that stage;
raw bulk files remain unchanged. The primary case-study PDF and its hash are
included separately in `data/US11847550.pdf` and `case_study_manifest.json`.
It was visually reviewed on pages 1–2 to verify the continuation chain.

## Reconstruct the original comparison frame

The frame is already supplied. If the preceding analysis's clean dataset is
available, the optional scope stage can regenerate it without modifying that
input:

```bash
python code/00_build_cohorts.py /path/to/clean_patent_company.csv.gz --output /tmp/rebuilt_cohort.csv
```

The report interpretation is specific to these source rows and is guarded by
the comparison-frame hash. A different source or scope requires revising the
interpretation and validation, not merely rerunning a template.

## What is included

- `code/`: source/cohort selection, bulk retrieval, extraction, technology
  analysis, visualization, report generation and verification/packaging.
- `data/cohort_frame.csv`: original selected identifiers and classifier values.
- `data/g_*_subset.csv.gz`: retained raw government metadata, including current
  and at-issue CPC records.
- `data/analysis_patent_cohorts.csv.gz`: one grant per row with text, CPC,
  filing-date and engineered feature columns.
- `data/data_dictionary.csv`, `text_rules.json` and provenance manifests.
- `outputs/tables/`: counts, exact partitions, phrase contrasts, score anomalies,
  timing, and robustness specifications.
- `outputs/figures/`: six GitHub-friendly SVG figures. PNG versions are regenerated by the pipeline.
- `outputs/technology_report.html` and `.md`: focused research findings.
- `outputs/statistical_analysis.*`: exact composition/share accounting and the
  limits of statistical inference for these cohorts.
- `outputs/cpc_text_quality.*`, `enrichment_audit.json`, `verification.json`.
- `outputs/research_log.*`: observation, hypothesis, decision, justification,
  result, limitation and reasonable alternatives for significant choices.
- `file_manifest.json`: SHA256 and size of every archived artifact.

## Interpretation

All work is exploratory, including hypotheses motivated by the original EDA.
Classifier cutoffs are operational definitions, not verified AI/ML truth.
The cohorts are a finite census of the specified supplied rows, not a census of
all inventions or corporate activity. Exact effects and definition/influence
checks are reported; no unsupported sampling confidence interval or confirmatory
p-value is attached to known finite counts. Sensitivity ranges are not CIs.

CPC codes and text themes overlap. Only expressly labeled partitions are additive.
The communications partition counts any communications-associated grant once;
it is not a causal allocation of innovation. Six missing-current-CPC reissues
remain in the data. At-issue sensitivity uses a paired-case subset (742 early,
784 recent NVIDIA grants), with omissions recorded and no main-analysis deletion.
Filing dates refer to direct applications, not earliest family priorities.
